THE ENGLISH TENSE EXPLORER — UPDATED MULTI-PAGE WEBSITE

This package contains the complete public website.

PAGES
- index.html                 Home
- explore.html               Explore & Understand (12 tense forms)
- grammar-reference.html     Interactive Grammar Reference + Verb Forms Explorer
- relationships.html         Clickable tense comparisons
- scenario-lab.html          Scenario Lab activities
- practice.html              Expanded Practice & Assessment

SHARED FILES
- css/style.css              Shared styling
- js/app.js                  Interactive features and question banks

LATEST LEARNING FEATURES
- Grammar Reference quick checks now use multiple-choice questions with feedback and explanations.
- Verb Forms Explorer includes a verb-form selector, form patterns, spelling guidance, a searchable list of 25 common irregular verbs, and 10 rotating quick-check questions.
- Grammar Library includes auxiliary verbs, sentence patterns, time expressions, subject–verb agreement, gerunds and infinitives, active/passive voice, stative/dynamic verbs, and modal verbs.
- Practice includes 5 questions for each of the 12 tense forms (60 focused questions), 20 comparison questions, and 24 mixed-tense questions.
- The separate 12-question diagnostic remains available.
- Practice answer options rotate so the correct answer is not always in the same position. Students can retry each set.

DEPLOYMENT
1. Extract this ZIP file.
2. Open the GitHub repository on the main branch.
3. Choose Add file > Upload files.
4. Upload all six HTML files and both folders (css and js) to the repository root.
5. Commit the changes to main. Replacing the existing files is intended.
6. Wait for GitHub Pages to publish, then test each page.

IMPORTANT
Keep css and js at the repository root. Do not place the files inside an extra nested folder. This package has been checked for JavaScript syntax and local page asset references, but it has not yet been deployed or fully browser-tested on the live site.
