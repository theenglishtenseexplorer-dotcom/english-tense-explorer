THE ENGLISH TENSE EXPLORER — MULTI-PAGE WEBSITE

WHAT'S INCLUDED
- index.html (Home)
- explore.html (12-form explorer)
- grammar-reference.html
- relationships.html
- scenario-lab.html
- practice.html
- css/style.css (shared visual system)
- js/app.js (shared interactions and learning content)

HOW TO PUBLISH ON GITHUB PAGES
1. Download and unzip this package.
2. Open your GitHub repository.
3. Upload the CONTENTS of this folder into the repository root (not the folder itself).
4. Allow GitHub to replace the existing index.html.
5. Commit the changes to the main branch.
6. Keep the css and js folders in the root, preserving their names.

IMPORTANT
Do not upload only index.html. The pages depend on css/style.css and js/app.js.
Do not rename the HTML pages or the css/js folders unless you also update their links.
